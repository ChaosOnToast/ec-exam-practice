Lesson 1: relational databases, data dictionaries and SQL.

Lesson 1 · in all 6 papers · 6 to 13 marks

Relational databases and SQL

Goal: read a schema, fill in a data dictionary and write a three-table query that runs first time.

Notes

Databases and SQL appeared in every paper we looked at, worth 6 to 13 marks each time, so this lesson comes first.

Keys link tables, joins go in WHERE

Keys

Primary key identifies each record in its table.

Foreign key holds a primary key from another table, which links them.

One-to-many runs from the PK side (one member) to the FK side (many bookings).

The SQL you need

Only SELECT, FROM, WHERE and ORDER BY are in the course.

One join condition in WHERE per link: three tables need two.

WHERE M.memberID = B.memberID
AND C.classID = B.classID

Mistakes that cost SQL marks

A missing join

Returns every combination of rows, with no error to warn you.

OR without brackets

AND is applied first. Write (a OR b) AND c.

Date ranges

Two conditions: date >= '2026-10-01' AND date <= '2026-10-31'.

Quotes

Text in single quotes, matching the data’s capitals. Numbers without quotes.

Data security and backup

Goal: match a threat to the measure that actually stops it, and justify two measures for a scenario.

Notes

Each threat has a measure that targets it

ThreatMeasure that targets it
Stolen or guessed passwordMulti-factor authentication, strong passwords

Intercepted data, stolen laptopEncryption in transit and at rest
Phishing, social engineeringOngoing staff training
Ransomware, hardware failure, disasterTested offsite backups, recovery plan
Malware, unauthorised network accessAntivirus, firewalls, updates

Lesson 2 · Data security and backup

Notes

Read the threat column first and ask the room for the measure before revealing it. The point is that each measure stops a specific threat: encryption does nothing about phishing, and training does nothing about a failed hard drive.

Backups: what a restore needs

Full

Copies everything. Slowest to make, simplest to restore.

Incremental

Changes since the last backup of any kind. Restore = full + every incremental after it.

Differential

Changes since the last full backup. Restore = full + the latest differential.

3-2-1 rule

3 copies, on 2 types of media, 1 offsite. Test that restores work.

Risk matrix

Rate each threat by likelihood × impact. Deal with high-high first.

Lesson 2 · Data security and backup

Notes

Quick check before the practice set: with a Sunday full backup and nightly incrementals, a Thursday lunchtime failure needs Sunday, Monday, Tuesday and Wednesday. With differentials it would need only Sunday and Wednesday.

Which backups does a restore need?

Lesson 2 · Data security and backup

Notes

Walk the two rows left to right. With incrementals, every night only copies what changed since the night before, so restoring Thursday needs the full backup plus all four. A differential copies everything since the last full backup, so only Sunday plus Thursday are needed.

Decision categories are a spectrum

Lesson 4 · Expert systems, decision support and hardware

Notes

Use this to frame any decision question: how much of the decision is fixed rules, and how much is judgement? Each category gets its own paragraph and its own stimulus example in a written answer.

Three categories of decision

CategoryWhat the system doesExample
StructuredApplies fixed rules and decidesAutomatic stock reordering
Semi-structuredAnalyses and flags, a person decidesFraud alerts reviewed by an analyst
UnstructuredSuggests options, no fixed procedureA board choosing a new market

DSS vs expert system

A DSS presents analysis so a person decides. An expert system concludes itself: knowledge base, inference engine, user interface.

Reasoning

Forward chaining starts from facts (monitoring). Backward chaining starts from a goal (testing one suspected cause).

Lesson 4 · Expert systems, decision support and hardware

Notes

Other inference techniques to mention briefly: truth maintenance (withdraws a conclusion when a fact changes), hypothetical reasoning (explores assumed alternatives), fuzzy logic (degrees of truth), ontology classification (“is a kind of”, so rules are inherited) and certainty factors.

Forward vs backward chaining

Lesson 4 · Expert systems, decision support and hardware

Notes

Forward chaining keeps applying rules to whatever facts arrive until a conclusion appears, so it suits monitoring. Backward chaining starts with a guess and looks for the facts that would prove it, so it suits testing one suspected fault or diagnosis.

Hardware: sense, decide, act

Sense

Sensors measure: temperature, proximity, light, moisture, cameras

Decide

Microcontroller or PLC compares readings with set limits

Act

Actuators and motors move: valves, vents, robotic arms

The sensor then reports the new reading, so the loop repeats. Other hardware: biometrics, haptics, touch and gesture, voice, VR and AR.

Lesson 4 · Expert systems, decision support and hardware

Notes

In written answers, name specific sensors, not just “sensors”: a proximity sensor detects parts on a conveyor, a camera checks for defects, a vibration sensor warns of a failing motor.

Answers and notes

Answers for going over: Q1 velocity. Q2 a warehouse holds cleaned, structured data; a lake holds raw data. Q3 the OAIC. Q4 consent and privacy, bias, copyright, ICIP, accuracy. Q5 a judgement supported by several issues, each tied to the stimulus: tracking purchases and in-store location with consent buried in the terms (privacy, Privacy Act and APPs), a large data store as a breach target (security), personalised pricing and sensitive inferences from purchases (ethics), sharing with “partner companies”, and the benefits of savings and convenience weighed against them.

Mistakes that cap extended responses

Writing everything you know

Answer the question asked. Content that is not linked to it earns nothing.

Stopping before the outcome

End every point with what the company or user gains or loses.

Only one level

“Individuals or society” questions reward both: one person’s job, then the wider effect.
